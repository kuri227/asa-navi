# Architecture Decision Records

仕様やアーキテクチャへ影響する判断を`NNNN-short-title.md`として記録する。

各ADRには次を含める。

- Status / Date
- Context / Problem
- Constraints
- Options
- Decision or Recommendation
- Consequences
- Existing feature / data impact
- Required user approval

仕様変更、有料サービス、破壊的DB変更、大きなnative module、ストア要件へ大きく影響する判断は、ADRを作成したうえで実装前にユーザーへ確認する。
